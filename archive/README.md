# Архив

Исторические варианты проекта. Каждый каталог — отдельная идея со своей
судьбой. Файлы здесь **не редактируются**: сохраняются как были, включая
кодировки (cp1251), переносы строк и баги.

Основная линия живёт в [`../src/`](../src/).

Полная инвентаризация с доказательствами происхождения —
[`../docs/ARCHIVE.md`](../docs/ARCHIVE.md).

## Правило

1. Сначала коллекция попадает в [`../refs/`](../refs/) — там она в git не идёт.
2. Разбираешь: PE-даты, символы, строки, диффы.
3. Осмысленное переезжает сюда **как есть**.
4. Описание — в [`../docs/ARCHIVE.md`](../docs/ARCHIVE.md).
