# 2015-03: макеты и иконки

## `mockups/`

Дизайн-цель 2015 года: чёрный фон, моноширинный шрифт, RGB-треугольник
по центру, поле ввода внизу.

| Файл | Что |
|---|---|
| `603p2.jpg`, `603p2_640_480_fix.jpg`, `CONBACK.png` | «Не нравится — не ешь.» |
| `jacob.png` | «Take it or leave it.» — тот же кадр по-английски |
| `tamag.png` | тамагочи-экран, «hungry» |
| `_NeOchen/` | скриншоты процесса: Paint с макетом и окно `HELLO`, Opera |

`_NeOchen` («не очень») — авторская пометка: сравнение макета с
результатом признано неудачным.

**Что выжило:** композиция. Чёрный фон, моноширинный шрифт, строка ввода
внизу, минимализм. Треугольник не выжил — в 2026-м его место занял текст.

## `icons/`

Серия `MFCRGB` — 32×32, семь итераций:

| Файл | Идея |
|---|---|
| `MFCRGB.png` … `_v5.png` | три кубика с буквами M, F, C |
| `MFCRGB_v6_RC1.png` | пирамида из трёх треугольников (RGB) |
| `MFCRGB_v7_NextGen.png` | планета Земля |
| `triforce.png` | трифорс |
| `isthisa.png` | «является ли это роликовые коньки» — мем-заглушка |

Ни одна не стала иконкой проекта. В 2026-м иконка сделана заново:
терминальный промпт `>` с курсором (`tools/gen_icon.py`).
