# 2012-07: консольный бот

Первая рабочая версия Codename Hello. Чистый C, без графики:
`printf` / `fgets` / массив фраз.

Шесть итераций за одну ночь 3–4 июля 2012:

```
hello_0_01.c   153 строки   базовый цикл
hello_0_02.c   217 строк    + размер консоли, replace, append
hello_0_02a.c  249 строк    + #include "SDL/SDL.h" (ещё не используется)
hello_0_04.c   358 строк    + SDL_Init, TTF_Init, DrawImage
main.c         249 строк    ветка от 0_02a
```

`bin/` — собранные exe с датами из PE-заголовков (03–04.07.2012).

**Ключевое:** функция `analyze()` сравнивала строки по два байта —
это уже биграммы, только на сырых байтах cp1251 вместо кодпоинтов.
Отсюда выросла современная `tm_dice_bigrams()`.
