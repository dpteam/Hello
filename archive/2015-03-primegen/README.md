# 2015-03: генератор простых чисел

Отдельная идея, к боту отношения не имеет: «Hello» как песочница для
Win32 + OpenGL.

## `console-gen/`

`hello.cpp` — консольный генератор. Внутри четыре бага подряд:

```cpp
n1 << rand();                  // сдвиг на случайное 0..RAND_MAX — UB
if (PrimeNumber(n2) == 2)      // функция возвращает 0/1, ветка мертва
n << n1prime + n2prime;        // n не инициализирован
```

## `gl-primegen/`

`main.cpp` — окно Win32 + OpenGL (`wglCreateContext`), треугольник,
звёздное поле, логирование в файл.

**Главный баг финала:** цикл сообщений стоит **до** цикла генерации,
поэтому числа начинают считаться только после закрытия окна.
`hello.log` содержит одну строку — `Info: OpenGL initialized`;
до `Info: Application closed` дело не дошло.
