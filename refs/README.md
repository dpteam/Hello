# Рабочая папка для разбора старых сборок

Сюда можно кидать что угодно: архивы, exe, dll, дампы, скриншоты —
содержимое этой папки **не попадает в git** (см. `.gitignore`).

## Порядок работы

1. Кладёшь коллекцию сюда.
2. Разбираешь: определяешь, из какого исходника и когда собрано,
   вытаскиваешь строки/символы/даты, восстанавливаешь утраченное.
3. Всё осмысленное уезжает в `archive/<год-месяц-идея>/` **как есть**.
4. Описываешь находку в [`docs/ARCHIVE.md`](../docs/ARCHIVE.md).
5. `refs/` снова пустеет — кроме этого файла.

## Инструменты

```bash
python tools/re/pe_info.py файл.exe       # секции, дата сборки, импорты, символы
python tools/re/pe_strings.py файл.exe    # ASCII-строки по секциям
python tools/re/pe_strings.py файл.exe --utf8   # UTF-8 / кириллица
python tools/re/diff_slices.py старый.c новый.c # что изменилось между срезами
```
